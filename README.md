# TrainableAI

TrainableAI is a web-based tool that makes creating machine learning models fast, easy, and accessible to everyone. It allows users to train models to recognize images, sounds, and poses without requiring any coding knowledge.

## Features

- **Image Recognition**: Train models to classify images using your webcam or uploaded files
- **Sound Recognition**: Train models to classify sounds using your microphone
- **Pose Recognition**: Train models to classify body positions using your webcam
- **User-Friendly Interface**: No coding required
- **On-Device Processing**: All data processing happens locally for privacy
- **Export Models**: Export trained models for use in your own projects

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/trainableai.git
cd trainableai
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will be available at `http://localhost:3000`.

## Usage

1. **Gather Examples**: Collect and group your examples into classes or categories
2. **Train Model**: Train your model and test it with new examples
3. **Export**: Export your model for use in your projects
